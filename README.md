**Lumen Drift** — pilot a light-ship through a collapsing nebula. Gather lumen orbs, dodge void shards, chain orbs into score-multiplying combos, and survive waves that grow faster and denser. Grab power-ups: shield (absorb one hit), magnet (pull orbs in), slow-time (the world crawls while you fly at full speed). Dash through danger with Space or a click; lose all three hull and the light fades.

- Mouse steers · WASD / arrow keys thrust · Space or click dashes · P pauses · R restarts
- Score, wave, hull, combo meter and dash cooldown on the HUD; best score saved in the browser
- Title, pause and game-over screens with stats (score, orbs, best combo)
- Synthesised WebAudio sound effects — no audio files, no network requests at all

## Run it

```sh
python3 -m http.server 8901 --directory game
```

Then open http://localhost:8901 in desktop Chrome.
